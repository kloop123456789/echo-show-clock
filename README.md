# Echo Clock & Weather

Amazon Echo Show 5（画面 960×480 / 縦横比 2:1）にぴったり収まるWebアプリです。
横にスワイプすると4つの画面が切り替わります。

1. **デジタル時計＋天気予報**
2. **アナログ時計**
3. **アラーム／ストップウォッチ／タイマー**
4. **カレンダー**

APIキーの登録やアカウント作成は不要で、`index.html` を開くだけで動きます。

---

## 画面の切り替え

画面を左右にスワイプすると切り替わります。下の6つの点をタップしても移動できます。
パソコンで見ているときは、キーボードの左右キーでも切り替えられます。

指で軽く払うだけでも切り替わります。ゆっくり動かす場合は、画面の幅の1割ほど
動かせば切り替わります。縦に大きく振れた指はスライドとみなしません。

### スマホで見るとき

縦長の画面では、内容が上下に積み替わって画面いっぱいに表示されます。
Echo Show 5 のような横長の画面では、これまでどおり左右に並びます。

### 1枚目：デジタル時計＋天気予報

| 位置 | 内容 |
| --- | --- |
| 左上 | 現在時刻（秒付き）、年月日と曜日、地点名、更新時刻と出典、日の出・日の入り、室温・湿度 |
| 右上 | いまの天気アイコン、気温、天気名、体感温度・降水確率・湿度・風速 |
| 左下 | 3時間ごとの予報（8コマ＝24時間先まで） |
| 右下 | 3日間の予報（最高／最低気温と降水確率） |

**日本の地点は気象庁の予報**を表示します（海外の地点は Open-Meteo）。詳しくは下の「使用している天気データ」を参照。

**天気の部分をタップすると、詳しい予報が開きます。**（下の「天気の詳細」を参照）

背景の色は「時間帯（朝・昼・夕・夜）× 天気」で自動的に変わります。晴れた昼は日差しの光が差し、
晴れた夜は星が浮かびます。

### 2枚目：アナログ時計

秒針がなめらかに動く時計です。右側に日付とデジタル表示、現在の天気、3日間の予報、室温・湿度が並びます。
天気や3日間の予報をタップすると、1枚目と同じく詳しい予報が開きます。

### 3枚目：カレンダー

その月のカレンダーです。詳しくは下の「カレンダー」をご覧ください。

### 4枚目：雨雲レーダー

気象庁の「雨雲の動き」を、1時間前から1時間先まで動かして見られます。
地図をタップすると、その場所を中心にできます。
詳しくは下の「雨雲レーダー」をご覧ください。

### 5枚目：世界時計

サンフランシスコ（PT）・ニューヨーク（ET）・UTC・ロンドン・パリ・北京の、いまの時刻が並びます。
右側では「現地の○時は、日本時間の何日何時か・あと何時間か」を計算できます。
詳しくは下の「世界時計」をご覧ください。

### 6枚目：アラーム／ストップウォッチ／タイマー／あと何日

上のタブで4つの機能を切り替えます。詳しくは下の「アラーム・タイマー・あと何日」をご覧ください。

### 隠し画面：ニキシー管時計

黒い背景に、オレンジに光る6本のニキシー管が並ぶ時計です。
通常の6画面には表示されません。

- **Echo Show・スマホ：** 1枚目の時計の数字、または2枚目のデジタル時刻を、素早く **5回タップ**します（タップ間隔は0.65秒未満）。
- **パソコン：** 入力欄や設定画面を開いていない状態で、半角英字で **`nixie`** と続けて入力します（文字間隔は1.5秒以内）。
- **戻る：** 左上の戻るボタン、`Esc`、もう一度 `nixie` と入力、または管の数字を5回タップすると元の画面に戻ります。

日付と時・分・秒は現在時刻に連動します。下部には選択中の場所・天気・気温と、
有効なアラーム／スヌーズのうち次に鳴る時刻を表示します。未設定の場合は「未設定」と表示されます。
天気をタップすると場所の設定、アラームをタップすると通常のアラーム画面を開けます。
隠し画面でもアラームとタイマーは動き、時刻になると通常どおり鳴動画面が表示されます。

表示モードはブラウザに保存され、再読み込み後も続きます。通常画面に戻すと保存が解除されます。
ガラス管と数字はSVGで描画するため、参考画像や外部画像の読み込みは不要です。

## 使い方

### 1. パソコンで確認する

`start.bat` をダブルクリックすると簡易サーバーが立ち上がります。
表示された `http://localhost:8765/` をブラウザで開いてください。

終了するときは、開いた黒い画面で `Ctrl` + `C` を押します。

### 2. Echo Show 5 に表示する

Echo Show 5 とパソコンを同じ Wi-Fi につないだうえで、次のどちらかの方法で開きます。

**方法A：パソコンをサーバーにする（お試し向け）**

1. `start.bat` を実行する
2. 画面に出た `IPv4 アドレス`（例 `192.168.1.10`）を控える
3. Echo Show 5 に「アレクサ、ブラウザを開いて」と話しかける
4. アドレス欄に `http://192.168.1.10:8765/` と入力する

この方法はパソコンの電源が入っている間だけ表示できます。

**方法B：どこかに公開して常時表示する（おすすめ）**

`index.html` `css` `js` `img` の4つをそのままレンタルサーバーや GitHub Pages、Netlify などに
アップロードすれば、パソコンを起動していなくても表示できます。

Echo Show 5 のブラウザでそのURLを開き、ホーム画面にブックマークしておくと便利です。

### 3. 全画面で表示する

画面右上の小さなアイコンを押すと、ブラウザのアドレス欄などが消えて全画面になります。

## GitHub Pages で公開する（常時表示するならこれ）

パソコンの電源を切っていても Echo Show 5 から見られるようにする手順です。
無料で使えます。GitHub Pages を無料で使うには、リポジトリを **Public（公開）** にする必要があります。
ソースコードが誰でも読める状態になりますが、このアプリには
パスワードなどの秘密情報は一切含めていません。

### 手順1：GitHub にリポジトリを作る

1. <https://github.com/new> を開く
2. **Repository name** に `echo-show-clock` と入力する
3. **Public** を選ぶ
4. `Add a README file` などのチェックは **すべて外す**（手元のファイルと衝突するため）
5. **Create repository** を押す

### 手順2：手元のファイルを送る（push）

**`github-push.bat` をダブルクリックしてください。**
GitHub のユーザー名を聞かれるので入力して Enter を押すだけです。
送信先の設定とアップロードをまとめて行います。

初回はブラウザが開くので、GitHub にサインインして許可してください。

> `push` は「手元の記録をインターネット上に公開する」操作です。実行すると
> ファイルの内容が誰でも見られる状態になります。

失敗しても何度でもやり直せます。ユーザー名を間違えた場合は、
もう一度 `github-push.bat` を実行すれば正しい送信先に上書きされます。

<details>
<summary>コマンドで実行したい場合</summary>

PowerShell で、このフォルダに移動してから1行ずつ実行します。
`あなたのユーザー名` は自分のものに置き換えてください。

```
git remote add origin https://github.com/あなたのユーザー名/echo-show-clock.git
```

```
git push -u origin main
```

Windows PowerShell（青くない、昔からある方）では `&&` でコマンドをつなげません。
かならず1行ずつ実行してください。

</details>

### 手順3：Pages を有効にする

1. リポジトリのページで **Settings** タブを開く
2. 左のメニューから **Pages** を選ぶ
3. **Source** を `Deploy from a branch` にする
4. **Branch** を `main`、フォルダを `/ (root)` にして **Save** を押す
5. 1〜2分待つと、ページ上部に公開URLが表示されます

公開URLは次の形になります。

```
https://あなたのユーザー名.github.io/echo-show-clock/
```

### 手順4：Echo Show 5 で開く

1. 「アレクサ、ブラウザを開いて」と話しかける
2. アドレス欄に上記の公開URLを入力する
3. 画面右上のアイコンを押して全画面にする

よく使うならブックマークしておくと、次回から数タップで開けます。

### あとから修正したとき

ファイルを直したら、このフォルダで次を実行すると公開版にも反映されます。
反映までは1分ほどかかります。

```
git add -A
git commit -m "fix: 表示を調整"
git push
```

見た目が変わらないときは、`index.html` の中の `style.css?v=13` などの
数字を増やしてから push してください。ブラウザが古い内容を覚えているのを防げます。

## アラーム・タイマー・あと何日

6枚目の画面にあります。設定内容はブラウザに保存されるので、
画面を切り替えても、再読み込みしても続きます。

音は端末のスピーカーから鳴ります。音量は Echo Show 本体の音量で調整してください。
なお、ブラウザの制限により**画面を一度タップしてからでないと音が出ません**。
アラームを設定する操作自体がタップになるので、通常は意識する必要はありません。

### アラーム

- 「アラームを追加」を押し、`＋` `−` で時刻を合わせて「決定」を押します
- **最大4件**まで登録できます
- カードの下のスイッチでオン・オフを切り替えます
- 時刻を押すと変更・削除ができます
- 「毎日くり返す」を外すと、1回鳴ったあと自動でオフになります
- 鳴っているあいだは「停止」と「5分後にもう一度」を選べます
- 止めなかった場合は15秒で自動的に止まります

#### 鳴ったときに目標・やることを表示する

アラームの設定画面の右側に「鳴ったときに表示すること」という入力欄があります。
ここに書いた内容が、時刻になったときに画面いっぱいに出ます。

- **1行だけ書いた場合**は、その言葉が大きく中央に出ます（目標の表示に向いています）
- **改行して複数書いた場合**は、点つきのリストになります（やることリストに向いています）
- 表示されるのは**4行まで**です。5行目以降は出ません
- 入力欄の下のボタンを押すと、よく使う言葉をタップだけで入れられます。
  一度使った言葉は自動的にこのボタンに並ぶので、次回から入力が要りません
- 空のままでも構いません。その場合は今までどおり時刻だけが出ます

アラームカードにも、設定した内容が小さく表示されます。
複数行のときは中黒（・）でつないだ形になります。

### ストップウォッチ

- 「スタート」で計測を始め、「ストップ」で止めます。止めたあとは「再開」できます
- 「ラップ」でその時点までの区間タイムを記録します
- 記録の中で**最速は緑、最遅は赤**で表示されます
- 「リセット」で最初に戻します（計測中は押せません）

### タイマー

- 1分・3分・5分・10分・15分・30分のボタンからすぐ選べます
- 円の中央を押すと、分と秒を自由に設定できます（最大99分59秒）
- 残り時間は円の減り具合でも分かります。**残り10秒からは赤**になります
- 0になると音が鳴り、画面に表示が出ます

### あと何日

「基本情報技術者試験まで あと115日」のように、決めた日までの**日数**を数えます。

- 「＋ 追加する」を押し、**なにの日か**と**いつか**を入れて「保存」
  - 名前は「試験」「資格試験」「誕生日」などの候補からも選べます
  - 日付の欄を押すと、端末のカレンダーから選べます
- **最大5件**まで登録でき、右側に近い順で並びます。押すとその日を大きく表示します
- 右上には**いまの時刻（秒まで）と日付**が出ます。勉強中に時間も確かめられるように
- 大きな表示では、残りの日数に加えて**何週と何日か**と、
  **登録した日から当日までのうち、どれだけ過ぎたか**を帯で出します（準備の進み具合の目安）
- 当日は黄色で「今日です」、過ぎた日は「終わりました ○日前」と出ます（右の一覧では薄く後ろに回ります）
- 名前や日付を直したいとき・消したいときは「編集」から

数えるのは日付の差なので、当日の朝でも夜でも「今日です」になります。
つけっぱなしにしていれば、夜中の0時に自動で1日減ります。

## カレンダー

3枚目の画面です。左側にその月にちなんだ意匠、右側にカレンダーが並びます。

### 月ごとの意匠

日本の四季の風物を、月ごとに違う絵で表示します。旧暦の月名と季節の言葉も添えています。

| 月 | 旧暦名 | 意匠 |
| --- | --- | --- |
| 1月 | 睦月 | 初日の出と松 |
| 2月 | 如月 | 梅 |
| 3月 | 弥生 | ひな人形 |
| 4月 | 卯月 | 桜 |
| 5月 | 皐月 | 鯉のぼり |
| 6月 | 水無月 | あじさい |
| 7月 | 文月 | 風鈴 |
| 8月 | 葉月 | 花火 |
| 9月 | 長月 | 十五夜の月とすすき |
| 10月 | 神無月 | もみじ |
| 11月 | 霜月 | いちょう |
| 12月 | 師走 | 雪の結晶 |

絵は `img/month-01.png` 〜 `month-12.png` に入っています。
差し替えたいときは、同じ名前で置き換えたうえで `js/calendar.js` の
`IMG_VER` の数字を増やしてください。ブラウザが古い画像を覚えているのを防げます。

その月の色にあわせて、今日の日付を囲む色も変わります。

### 日付の見かた

- 日曜と**祝日は赤**、土曜は青で表示します
- 祝日には日付の下に小さな点が付きます
- 今日の日付は、その月の色で塗って示します
- カレンダーの下に、その月の祝日を一覧で並べます

### 前後の月を見る

年月の右にある `‹` `›` で月を移動できます。今月以外を見ているときは「今日」ボタンが出るので、
押せばすぐ戻れます。他の画面にスワイプで移動しても、自動的に今月に戻ります。

### 祝日について

祝日はプログラムで計算しています。ハッピーマンデー（成人の日・海の日・敬老の日・スポーツの日）、
春分の日と秋分の日、振替休日、国民の休日に対応しています。

1980年から2099年まで正しく表示されますが、**2020年と2021年の五輪にともなう特例移動には
対応していません**。また、法律が変わった場合は `js/calendar.js` の修正が必要です。

## 場所の変更

地点名（初期値は「東京」）をタップすると設定画面が開きます。

- **検索** … 都市名を入れて検索します。日本語で見つからないときはローマ字（`Osaka` `Kyoto` など）をお試しください
- **現在地を使う** … 端末の位置情報から自動で設定します（許可が必要です）
- 選んだ場所はブラウザに保存され、次回からその場所で表示されます

### URLで直接指定する

設定画面を使わずに、URLのうしろに付けて指定することもできます。

```
index.html?lat=34.69&lon=135.50&name=大阪
```

| パラメータ | 意味 |
| --- | --- |
| `lat` | 緯度 |
| `lon` | 経度 |
| `name` | 画面に出す地点名 |
| `step` | 時間ごと予報の間隔（**Open-Meteo のときだけ**）。`1` で1時間ごと、`2`（初期値）で2時間ごと、`3` で3時間ごと。気象庁は発表が3時間ごとなので常に3時間ごと |
| `bg` | `fixed` を指定すると背景の明るさを一定にする（つけっぱなし用） |
| `sb` | SwitchBot の中継URL（室温・湿度）。`/api/switchbot` のような書き方もできる |
| `wx` | `openmeteo` を指定すると、日本の地点でも Open-Meteo の予報を使う（見比べたいとき用） |

URLで指定した場合は、保存された場所より優先されます。

## 世界時計

5枚目の画面です。AI の新しいモデルの発表などは「10am PT」のように
現地の時刻で告知されることが多いので、それが日本時間で何日の何時なのか、
あと何時間なのかをすぐ確かめられるようにしています。

### 左：いまの時刻

| 表示 | 地域 |
| --- | --- |
| サンフランシスコ（PT） | 米西海岸。OpenAI・Anthropic・Google などの発表でよく使われる |
| ニューヨーク（ET） | 米東海岸 |
| 協定世界時（UTC） | 世界共通の基準の時刻 |
| ロンドン（UK） | 英国 |
| パリ・ベルリン（CET） | 中欧 |
| 北京・上海（CN） | 中国 |

それぞれ、日本から見て**前日か同じ日か**と、**時差**が出ます。
夏時間の地域は「夏時間」と出ます（米国は3月中旬〜11月上旬、欧州は3月末〜10月末）。
昼は太陽、夜（18時〜翌6時）は月のしるしが付きます。

### 右：時差の計算

1. 上のボタンで、どこの時刻かを選ぶ（**PT・ET・UTC・UK・CET・CN**）
2. **＋ −** で時と分を合わせる（分は5分ずつ。押し続けると連続で動きます）
3. **‹ ›** で日付を変える

すると、**日本時間で何日の何時か**と、**あと何時間か**が出ます。

- 地域を切り替えたときは、その地域で**次に来るその時刻**に日付を合わせます
- 1時間を切ると、残り時間が秒まで出て黄色になります
- 過ぎた時刻は「○時間前に過ぎました」と出ます
- 入力した時刻はブラウザに保存されます（1日以上前に過ぎたものは、次に開いたとき初めからになります）

例：「10am PT」なら、PT を選んで 10:00 に合わせると、
いまの時期（夏時間）は **日本時間の翌日 午前2時** と出ます。

夏時間の切り替えは、ブラウザが持っている世界の時刻データで計算しているので、
切り替えの日をまたいでも正しく出ます（11月に米国の夏時間が終わると、日本との時差が1時間広がります）。

## 雨雲レーダー

4枚目の画面です。気象庁の**高解像度降水ナウキャスト**を、
国土地理院の地図に重ねて表示します。

- **1時間前から1時間先まで**、10分ごとのコマで動きます（自動で再生）
- 「実況」は観測、「予測」は気象庁の予測です
- 地図の中心が、設定している地点です（白い丸）
- **＋ −** で表示の広さを変えられます（選んだ広さは記憶します）
- 下の帯のコマをタップすると、その時刻で止まります。左の丸いボタンで再生・停止

### 中心の場所を変える

**地図をタップすると、その場所が中心になります。**
隣町や、これから向かう先の雨雲を見たいときに使えます。

- 中心をずらしている間は、左上に **「◎ 〇〇に戻す」** が出ます。押すと元の地点に戻ります
- 設定している地点の位置には、黄色い印と地名が出ます
- ずらした中心はブラウザに保存され、次に開いたときもそのままです
- 場所の設定（地名）を変えると、中心も新しい地点に戻ります

指で動かして地図をずらす方式にしていないのは、画面を切り替えるスワイプが
できなくなってしまうためです。タップだけで指定できるようにしています。

### 通信量について

この画面を**表示している間だけ**読み込みます。ほかの画面にいるときは何も取りません。
表示したままにしていると5分ごとに新しい雨雲に入れ替わります（1回あたり数百KBほど）。
地図そのものは一度読めば使い回されます。

### 出どころ

| 表示 | 出どころ |
| --- | --- |
| 雨雲 | 気象庁 高解像度降水ナウキャスト |
| 地図 | 国土地理院（白地図）。暗い画面に合わせて色を反転して使用 |

雨雲の色は、気象庁の**1時間に降る雨の量（mm）**の配色に合わせています。
画面左下に凡例を出しています。

日本国外の地点では、気象庁のナウキャストの範囲外のため表示できません
（その旨のメッセージが出ます）。

### 仕組みのメモ

気象庁の雨雲タイルは**偶数の拡大率（4・6・8・10）にしか中身がなく**、
奇数を指定すると中身のない画像が返ってきます。
そのため奇数の広さのときは、ひとつ下の偶数のタイルを2倍に引き伸ばして重ねています。

また、いちばん弱い雨の色（ほぼ白）で地図が埋もれてしまうため、
海岸線や県境の線は雨雲の**上にも**薄く重ねています。

## 天気の詳細

予報の部分をタップすると、1週間先までの詳しい予報が開きます。

| タップした場所 | 開く日 |
| --- | --- |
| いまの天気（1枚目の右上、2枚目の右側） | 今日 |
| 3時間ごとのコマ | 今日。そのコマの列に枠が付く |
| 3日間のコマ | その日 |
| 更新時刻の横の「出典：気象庁」 | 今日。出典の帯が光る |

### 画面の見かた（気象庁のとき）

- **上のタブ** … 日付の切り替え（今日から8日分）。天気と最高／最低気温も出ています
- **左** … その日のまとめ
  - 天気、最高／最低気温、気象庁の予報文（「くもり 所により 夜 雨」など）
  - 降水確率、波の高さ（海に面した地域）、週間予報の信頼度、日の出・日の入り
  - 今日の最高・最低は、発表の時間を過ぎるとアメダスの実測値で表示します（「実測値」と出ます）
- **右（今日・明日）** … 3時間ごとの天気・気温（折れ線）・降水確率・風
  - 今日は「いま」から24時間分。日付をまたぐところに「明日0時」の区切りが入ります
  - **降水確率は気象庁の発表どおり6時間ごと**なので、2列ずつつながって表示されます
  - 風は「3〜5 m/s」のような幅で出ます（気象庁の発表の形）。その下に風の予報文
- **右（それより先の日）** … 週間予報の数字
  - 降水確率、最高／最低気温と**予想範囲**、**信頼度**、平年値
  - 3時間ごとの予報は、気象庁から発表の翌日いっぱいまでの分しか出ていないためです
- **下の帯** … 出典と、どの予報区の何時発表の予報か、いまの気温をどの観測所で測ったか

週間予報の信頼度は、降水の有無の予報の確からしさで、気象庁の説明は次のとおりです。

| 信頼度 | 意味 |
| --- | --- |
| A | 適中率が明日の予報並みに高い。翌日に予報が変わる可能性がほとんどない |
| B | 適中率が4日先の予報と同程度。翌日に予報が変わる可能性が低い |
| C | 適中率が B より低い、または翌日に予報が変わる可能性が B より高い |

海外の地点（Open-Meteo）では、降水量・最大風速・紫外線が出る代わりに、予報文・波・信頼度は出ません。

### 閉じかた

- 右上の **×**
- 外側の暗い部分をタップ
- 何も触らずに **60秒** たつと自動で閉じます（つけっぱなしの時計を覆い続けないため）
- キーボードなら Esc。← → で日付を切り替えられます

スワイプで画面を切り替えるときは、予報のコマの上から指を動かしても大丈夫です
（指がほとんど動かなかったときだけタップとみなします）。

## 室温・湿度を出す（SwitchBot）

SwitchBot の温湿度計を持っていれば、**部屋の実際の気温と湿度**を画面に出せます。
1枚目では日の出・日の入りの右に、2枚目では地名の右に、小さく並びます。

```
日の出 05:21　日の入 17:53　⌂ 24.3° 52%
```

未設定のときは何も出ません（見た目は元のままです）。

### なぜ「中継役」が必要なのか

SwitchBot の API は、**ブラウザから直接読むことができません**。
よそのサイトからの読み取りを許す印（CORS ヘッダ）を返さないので、Chrome が通信を止めてしまいます。

また、SwitchBot のトークン（合鍵のようなもの）をブラウザ側に置くと、
GitHub Pages のような公開ページでは他人に見られてしまう恐れがあります。

そこで、間に小さな中継プログラムを1つ置きます。

```
Echo Show の Chrome  →  中継役（Cloudflare）  →  SwitchBot
   温度と湿度だけ受け取る    ここにトークンを置く
```

トークンは中継役の側に置いたままになり、ブラウザには数字だけが渡ります。

中継役は **Vercel** か **Cloudflare Workers** のどちらかに置けます。
すでに Vercel を使っているなら Vercel が簡単です（このリポジトリをそのまま置けます）。

### 手順1：SwitchBot のトークンを取る（共通）

1. スマホの **SwitchBot アプリ** を開く
2. 右下の **プロフィール** → **設定**
3. **アプリバージョン** を **10回** 続けてタップする（開発者向けオプションが出ます）
4. **開発者向けオプション** を開く
5. **トークン** と **クライアントシークレット** の2つをコピーしておく

> この2つは合鍵です。人に見せたり、チャットに貼ったりしないでください。

温湿度計が SwitchBot アプリに追加済みで、**ハブ（Hub Mini / Hub 2 など）とつながっている**
ことも確認してください。ハブ経由でないと、外部から値を読めません。

### 手順2：Vercel に置く（おすすめ）

このリポジトリには、Vercel 用の中継役が [`api/switchbot.js`](api/switchbot.js) として入っています。
**リポジトリをそのまま Vercel に置くだけ**で、時計アプリと中継役が同時に動きます。

1. <https://vercel.com/new> を開く
2. **Import Git Repository** から `echo-show-clock` を選び **Import**
3. Framework Preset は **Other** のまま、何も変えずに **Deploy**
4. 1分ほどで `https://echo-show-clock-〇〇〇.vercel.app/` ができます

次にトークンを登録します。コードには書かず、Vercel の金庫に入れます。

5. プロジェクトの **Settings** → **Environment Variables**
6. 次の2つを追加する（Production・Preview・Development すべてにチェック）

   | Key | Value |
   |-----|-------|
   | `SWITCHBOT_TOKEN` | 手順1のトークン |
   | `SWITCHBOT_SECRET` | 手順1のクライアントシークレット |

7. **Save** を押す
8. **Deployments** → 一番上の … → **Redeploy** を押す
   （環境変数は、入れ直してからでないと反映されません）

`https://〇〇〇.vercel.app/api/switchbot` をブラウザで開いて、こう出れば成功です。

```json
{ "name": "室内", "temperature": 24.3, "humidity": 52, "battery": 96, ... }
```

### 手順3：時計アプリに登録する

**Vercel の URL を Echo Show で使う場合（おすすめ）**

Echo Show で開く URL を `https://〇〇〇.vercel.app/?bg=fixed` に変えます。
時計も中継役も同じ場所にあるので、設定画面の
**「室温・湿度（SwitchBot）」** の欄には `/api/switchbot` と入れるだけで済みます。

**GitHub Pages のまま使う場合**

設定画面の欄に、`https://〇〇〇.vercel.app/api/switchbot` を丸ごと貼り付けます。
別の場所から読むことになりますが、中継役が読み取りを許可しているので動きます。

どちらの場合も、**保存** を押して
「取得できました：室内 24.3° 52%」と緑で出れば完了です。

### Cloudflare Workers に置く場合

Vercel を使わない場合はこちらです。手順は
**[`switchbot-proxy/README.md`](switchbot-proxy/README.md)** にあります。
中身は Vercel 版と同じで、無料枠で動きます。

### 温湿度計が複数ある / うまく選ばれないとき

中継役の URL のうしろに `?list=1` を付けると、手持ちの機器の一覧が出ます。

```
https://〇〇〇.vercel.app/api/switchbot?list=1
```

`"温湿度計": true` になっているものの `deviceId` をコピーして、
環境変数に **`SWITCHBOT_DEVICE_ID`** として登録してください。
画面に出す名前を変えたいときは **`SWITCHBOT_DEVICE_NAME`** に `リビング` などを入れます。

### 任意：URL を知られても読まれないようにする

中継役の URL を知っている人なら誰でも、部屋の温度を見られます。
気になる場合は、環境変数 **`ACCESS_KEY`** に好きな文字列を登録し、
時計アプリに入れる URL を `.../api/switchbot?key=好きな文字列` にしてください。

読み取れるページを限定したい場合は、**`ALLOW_ORIGIN`** に
`https://kloop123456789.github.io` を登録します。

### うまくいかないとき

| 出てくるもの | 原因と対処 |
|---|---|
| `statusCode 401` | トークンかシークレットが違う。入れ直して Redeploy する |
| `statusCode 161` | 機器がオフライン。電池とハブとの距離を確認する |
| `statusCode 171` | ハブがオフライン。ハブの電源と Wi-Fi を確認する |
| `温湿度計が見つかりませんでした` | `?list=1` で ID を調べ、`SWITCHBOT_DEVICE_ID` を登録する |
| `SWITCHBOT_TOKEN と…設定してください` | 環境変数を入れたあと Redeploy していない |
| ログイン画面が出る | Vercel の Settings → Deployment Protection を確認する |
| 時計側で「取得できません」 | URL の打ち間違い。ブラウザで直接開いて確かめる |

SwitchBot API は **1日1万回** まで呼べます。
このアプリは5分おき（1日約288回）なので、余裕があります。

### 動きかた

- 5分おきに取りに行きます（室温はゆっくりしか変わらないため）
- 失敗したときは1分後に再試行します
- 30分以上古い値になったら、表示を消します（古い数字を出し続けないため）
- 取得できなくても、時計と天気はそのまま動きます

## つけっぱなしで使うとき

Echo Show などに24時間表示し続ける場合の設定です。

### 明るさが周期的に変わるとき

原因は2つ考えられます。

**1. 端末が画面を暗くしている（こちらが主な原因）**

Android系のOSは、一定時間さわらないと画面を暗くし、やがて消します。
このアプリは表示中ずっと「画面を消さないで」と端末に頼むようにしていますが、
OS側の設定が優先される場合があります。端末の設定で次を確認してください。

- **明るさの自動調節（アダプティブ・ブライトネス）をオフ**にする。
  周囲の明るさに反応して勝手に明暗が変わるのを止められます
- **画面消灯までの時間を「なし」**にする
- LineageOS などでは、開発者向けオプションの
  **「充電中は画面をスリープさせない」**も有効です

なお「画面を消さない」機能はブラウザの制限で **https のページでしか働きません**。
GitHub Pages で公開した URL なら問題ありません。

**2. アプリの背景色が変わっている**

このアプリは通常、時間帯と天気にあわせて背景の色を変えます。
晴れた昼は明るい青、夜は濃紺になり、天気が変わると10分ごとに色が切り替わります。

固定したいときは、URL のうしろに `?bg=fixed` を付けてください。

```
https://（あなたのURL）/?bg=fixed
```

濃紺の背景で固定され、日差しの光や星の明滅も出なくなります。
時刻・天気・予報の中身はこれまでどおり更新されます。

場所の指定と組み合わせるときは `&` でつなぎます。

```
index.html?lat=34.69&lon=135.50&name=大阪&bg=fixed
```

## 更新のタイミング

- 時計は1秒ごと
- 天気は10分ごとに自動で取り直します
- 雨雲レーダーは、その画面を表示している間だけ5分ごとに取り直します
  - 気象庁の予報そのものは **5時・11時・17時** に発表されます（荒天時などは臨時に更新）

- 取得に失敗したときは画面下に赤いメッセージが出て、1分後に自動で再試行します（そのあいだ直前の予報を表示し続けます）
- 画面が復帰したときや、ネットにつながり直したときは、すぐに取り直します

## 使用している天気データ

### 日本の地点：気象庁

気象庁ホームページが公開しているデータを、ブラウザから直接読んでいます。**無料・登録不要**です。

| 表示 | 使っているもの |
| --- | --- |
| いまの気温・湿度・風速 | **アメダス**（一番近い観測所の10分ごとの実測値） |
| いまの天気・3時間ごとの予報 | **地域時系列予報**（天気・気温・風。発表の翌日いっぱいまで） |
| 天気・降水確率・最高/最低気温（今日〜明後日） | **府県天気予報**（降水確率は6時間ごと） |
| 4日目以降 | **週間天気予報**（天気・降水確率・気温の予想範囲・信頼度・平年値） |
| 体感温度 | アメダスの気温・湿度・風速から計算（計算値） |
| 日の出・日の入り | 緯度経度から天文計算（計算値。国立天文台の値と1〜2分ずれることがあります） |

- 予報文や降水確率は、テレビや気象庁ホームページの天気予報と同じものです
- いまの天気は3時間ごとの予報をもとにしていますが、**アメダスで実際に雨が観測されているときは「雨」** にします
- 地点からどの予報区を使うかは、[国土地理院の逆ジオコーダ](https://maps.gsi.go.jp/development/api.html)で市区町村を調べ、気象庁の区域表と突き合わせて決めています（結果は端末に保存し、地点を変えるまで調べ直しません）

**利用条件**：気象庁ホームページのコンテンツは[公共データ利用規約](https://www.jma.go.jp/jma/kishou/info/coment.html)に準拠し、
出典の記載と、加工した場合はその旨の明記が必要です。
このアプリはアイコンや並べ方を変えて表示しているため、
1枚目に「出典：気象庁」、天気の詳細の下の帯に「気象庁ホームページ（…）を加工して作成」と出しています。

**注意**：これらのデータは気象庁が API として保証しているものではなく、**形式や URL が予告なく変わることがあります**。
取れなくなったときは、自動で Open-Meteo の予報に切り替えて表示を続け、画面下に知らせを出します
（出典の表記も「Open-Meteo」に変わります）。気象庁から取れるようになれば、次の更新で自動的に戻ります。

### 海外の地点：Open-Meteo

気象庁は日本しか予報していないため、海外の地点では [Open-Meteo](https://open-meteo.com/)（スイスの無料サービス）を使います。
URL に `&wx=openmeteo` を付けると、日本の地点でも Open-Meteo で表示できます。

データは **CC BY 4.0** で、表示する場所の近くに「Open-Meteo」の名前とリンクを出すことが利用の条件です。

Open-Meteo は各国の数値予報モデルの計算結果を配信していて、地点ごとにモデルを自動で選びます。
2026年9月14日に各地の値をモデルごとに1時間ずつ突き合わせたところ、次のとおりでした。

| 地点 | 1〜3日目 | 4日目以降 |
| --- | --- | --- |
| 東京・大阪・仙台・福岡 | 気象庁メソモデル（MSM・5km）と完全一致 | ECMWF（欧州・9km）と完全一致 |
| 札幌・那覇・石垣島 | ECMWF（9km）と完全一致 | ECMWF |

これは**予報官の手が入る前の計算結果**で、気象庁の天気予報とは別物です。
特に降水確率は、Open-Meteo が別のアンサンブル予報から出した値で、気象庁の降水確率とは数字が違うことがあります。
天気の詳細の下の帯に、その地点で使われているモデルを出しています。

天気の記号は WMO（世界気象機関）の天気コードにもとづき、日本語名とアイコンに変換しています。

## 表示を調整したいとき

`js/app.js` の冒頭にある設定値を書き換えると、動きを変えられます。

| 設定名 | 初期値 | 内容 |
| --- | --- | --- |
| `DEFAULT_PLACE` | 東京 | 初回に表示する場所 |
| `WEATHER_INTERVAL` | 10分 | 天気を取り直す間隔 |
| `HOURLY_COUNT` | 8 | 時間ごと予報のコマ数 |
| `DAILY_COUNT` | 3 | 日ごと予報の日数 |

アラームとタイマーの設定は `js/tools.js` の冒頭にあります。

| 設定名 | 初期値 | 内容 |
| --- | --- | --- |
| `MAX_ALARMS` | 4 | 登録できるアラームの数 |
| `MAX_MEMO_LINES` | 4 | 鳴ったときに表示する行数の上限 |
| `DEFAULT_LABELS` | 5語 | 入力欄の下に最初から並ぶ言葉 |
| `RING_LIMIT` | 15秒 | 止めなかったときに自動で鳴り止むまでの時間 |
| `SNOOZE_MS` | 5分 | 「5分後にもう一度」の待ち時間 |

文字の大きさや余白は `css/style.css` の `--u` を基準にしています。
`--u` は画面幅の1%にあたる値なので、すべての数値がまとめて拡大・縮小されます。

CSSやJavaScriptを書き換えたのに表示が変わらないときは、`index.html` の中の
`style.css?v=13` `app.js?v=13` などの数字を増やしてください。ブラウザが古い内容を
覚えてしまうのを防げます。
